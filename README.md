# TrashDetection

An AI-powered computer vision project for automated trash detection and classification using deep learning and machine learning techniques.

## Overview

TrashDetection explores the use of modern machine learning approaches for identifying and classifying waste objects from images. The project investigates multiple model architectures, including Convolutional Neural Networks (CNNs), Vision Transformers (ViTs), Multilayer Perceptrons (MLPs), and Random Forest classifiers, with the goal of improving automated waste recognition.

Applications of this work include:

* Smart recycling systems
* Environmental monitoring
* Waste management automation
* Sustainable city infrastructure
* Computer vision research

## Features

* Image-based trash classification
* Deep learning models using CNN architectures
* Vision Transformer implementation
* Traditional machine learning baselines
* Model evaluation and performance comparison
* Exploratory data analysis and visualization

## Models Explored

### Convolutional Neural Networks (CNN)

CNNs were used as a baseline deep learning architecture for image classification tasks. Their ability to learn hierarchical visual features makes them particularly effective for object recognition problems.

### Vision Transformers (ViT)

Vision Transformers were implemented to evaluate transformer-based approaches for visual understanding. These models leverage self-attention mechanisms to capture long-range spatial relationships within images.

### Multilayer Perceptrons (MLP)

MLP-based architectures were investigated as lightweight alternatives and as components of ensemble workflows.

### Random Forest

Random Forest models served as a traditional machine learning baseline for comparison against deep learning methods.
